# VectorRedactor_Interface

Редактор векторной графики на C++, построенный на **архитектуре ядра с использованием паттерна Singleton**.

## Структура проекта

```text
SDK/                    # Актуальный код проекта
├── Core/               # Ядро приложения, глобальная точка доступа (к плагинам, рендеру, логгеру...)
├── Interfaces/         # Интерфейсы сервисов (например, IPlugin, IToolManager)
└── Utils/              # Минимально необходимые утилиты, базовые классы (AObject, Vec2f, ...)

examples/               # Примеры, важные идеи

Formater.md             # Правила форматирования кода (см. ниже)
README.md
```

## Основные правила

- Синглтон ядра приложения, или глобальная точка доступа к приложению, определена в `SDK/Core/`.
- Интерфейсы различных сервисов, которые требуются для работы плагинов - `SDK/Interfaces/`.
- Минимально необходимые классы для работы - `SDK/Utils/`.
- Каталог `examples/` предназначен только для примеров.

## Форматирование кода

**Весь код должен соответствовать правилам `clang-format`.**

Инструкции по настройке и использованию см. в файле [`Formater.md`](Formater.md).

## Соглашение о сообщениях коммитов

Сообщения коммитов должны соответствовать формату:

`[Область] тип: краткое описание`

**Область (Scope)** — модуль или часть проекта, в которой выполняются изменения, например: `[General]`, `[Kernel]`, `[Interface]`, `[Event]`, `[Vec2f]`, `[Plugin]`.

**Тип (Type)** — один из следующих вариантов:

| Тип | Значение |
|---|---|
| `feat` | Добавление новой функциональности |
| `fix` | Исправление ошибки |
| `refactor` | Изменение кода без исправления ошибок и добавления новой функциональности |
| `docs` | Изменения только в документации |
| `style` | Изменения форматирования, не затрагивающие логику кода |
| `test` | Добавление или исправление тестов |
| `chore` | Сборка, инструменты разработки и прочие вспомогательные изменения |

### Примеры

```text
[General] feat: add singleton kernel skeleton
[Kernel]  fix: correct Vec2f orthogonal direction
[Event]   refactor: replace union with std::variant
[Plugin]  feat: add plugin manager interface
[General] docs: update README
```
